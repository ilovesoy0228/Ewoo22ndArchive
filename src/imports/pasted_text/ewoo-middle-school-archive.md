Create a complete desktop web design for a digital graduation archive called:

“EWOO MIDDLE SCHOOL 22nd ARCHIVE”

The archive documents three years of memories from Ewoo Middle School’s 22nd graduating class, from 2024 to 2026.

IMPORTANT:
This is NOT a normal modern dashboard, portfolio, or card-based website.

The website should visually feel like a beautiful physical book that has been transformed into a digital interactive archive.

The overall feeling should be:
- clean
- warm
- youthful
- simple
- quiet
- sentimental but NOT overly emotional
- modern
- minimal
- like a contemporary photo book / editorial book
- like a real graduation album
- slightly playful through photographs, handwritten notes, and small illustrations

DO NOT make it look vintage, retro, old-fashioned, or antique.

DO NOT use:
- yellowed paper
- brown vintage colors
- old newspaper textures
- leather textures
- excessive scrapbook decorations
- retro typography
- excessive paper wrinkles
- overly decorative elements
- complicated animations
- excessive shadows
- overly rounded modern UI cards

The website should feel like:
“a real book, but redesigned as a modern website.”

--------------------------------------------------
1. OVERALL WEBSITE STRUCTURE
--------------------------------------------------

Create the website as ONE continuous digital book.

The main structure is:

1. Closed Book Cover
2. Open Book / Main Archive
3. Grade Records
4. Other Activities
5. Guest Book

Do NOT create separate pages for every student.

There will NOT be individual student profile pages.

The website should mainly be a long scrollable digital book.

Different sections should exist inside the same website.

--------------------------------------------------
2. CLOSED BOOK COVER
--------------------------------------------------

The very first screen should look like a CLOSED hardcover book.

The user should first see a clean book cover.

The cover should be centered on a light neutral background.

Book cover text:

EWOO
MIDDLE SCHOOL

22nd ARCHIVE

2024 — 2026

Optional small subtitle:

DIGITAL GRADUATION ARCHIVE

The cover should be extremely simple.

Use generous whitespace.

The cover should feel like a contemporary art book or high-quality graduation album.

Use a soft off-white / warm white book cover.

Add a very subtle shadow underneath the book so it feels physical.

Do not use vintage textures.

The book should look premium but still youthful and appropriate for middle school students.

--------------------------------------------------
3. OPENING THE BOOK
--------------------------------------------------

When the user enters the archive, the closed book transitions into the main archive.

Keep the animation very subtle.

Do NOT create a dramatic 3D book animation.

A simple smooth transition is enough.

After opening, the user sees the first page of the digital book.

The entire website should now behave like a long book that can be scrolled vertically.

--------------------------------------------------
4. TOP INDEX NAVIGATION
--------------------------------------------------

IMPORTANT:

Do NOT place index tabs on the left or right side of the book.

There should be NO vertical side navigation.

Instead, create a horizontal index navigation at the TOP of the open book.

The index should visually feel like actual index tabs attached to the top edge of a physical book.

The index should always remain visible at the top while the user browses the archive.

The top navigation contains exactly three main categories:

학년별 기록
그 외 활동
Guest Book

Use a very clean horizontal layout.

The index should look like physical paper tabs, but in a modern minimal style.

Do not make the tabs overly decorative.

--------------------------------------------------
5. INDEX HOVER INTERACTION
--------------------------------------------------

When the mouse hovers over:

“학년별 기록”

show a small dropdown menu underneath it.

Dropdown items:

1학년
2학년
3학년

The dropdown should be clean and minimal.

The default dropdown text is dark gray.

When the cursor hovers over one item, that item should change to a calm sky-blue / soft blue accent.

When the user clicks:

1학년 → smoothly scroll to the beginning of the 1st-year section.

2학년 → smoothly scroll to the beginning of the 2nd-year section.

3학년 → smoothly scroll to the beginning of the 3rd-year section.

IMPORTANT:
Do NOT reload the page.

Do NOT create a new page.

Use smooth scrolling within the same long digital book.

--------------------------------------------------
7. GUEST BOOK INDEX
--------------------------------------------------

Clicking it should smoothly scroll directly to the Guest Book section at the end of the archive.

The Guest Book should also be accessible from the main navigation at any time.

--------------------------------------------------
8. MAIN HOME / PROLOGUE
--------------------------------------------------

Immediately after opening the book, create a simple opening page.

This page should introduce the archive.

Title:

EWOO MIDDLE SCHOOL
22nd ARCHIVE

2024 — 2026

PROLOGUE

This is where the creator will later write:

- why the creator chose to archive the three years
- a short message to the 22nd graduating class
- the creator’s personal perspective on school life

Do NOT fill this section with a long fictional essay.

Create a beautiful, generous text area where the actual writing can later be inserted.

The layout should feel like the first page of a book.

Keep it quiet and spacious.

--------------------------------------------------
9. PERSONAL PERSPECTIVE
--------------------------------------------------

The archive should communicate one consistent personal perspective.

The current perspective is:

“다정함으로 바라본 우리 학교”

Meaning:

“Looking at our school through kindness.”

IMPORTANT:
Do NOT write this phrase everywhere.

Do NOT make the website overly sentimental.

Instead, communicate the perspective subtly through:

- warm but simple writing
- small everyday moments
- photographs of ordinary school life
- student voices
- interviews
- handwritten notes
- small details that might otherwise be forgotten
- imperfect but genuine memories

The design should feel like the creator is carefully collecting ordinary moments that were meaningful to the students.

--------------------------------------------------
15. INTERVIEW DESIGN
--------------------------------------------------

The archive will contain interviews with students.

The interviews should feel conversational and personal.

Do NOT use formal school-report language such as:

“OOO 학생은…”

Instead, create space for questions and natural answers.

Possible question examples:

“가장 기억에 남는 순간은?”

“그때 어떤 기분이었어?”

“3년 동안 가장 많이 웃었던 순간은?”

“다시 돌아간다면 기억하고 싶은 순간은?”

However, do not fill the design with too many questions.

Create a flexible editorial text area where the actual interview content can be inserted later.

--------------------------------------------------
16. PHOTOGRAPH DESIGN
--------------------------------------------------

Photographs will be collected from classmates later.

Design flexible photo areas for approximately 1–3 photographs per section.

Photos should feel like photographs placed inside a real book.

Use:

- subtle white borders
- simple captions
- occasional slight rotation
- very subtle tape-like detail if appropriate

But keep everything minimal.

Do NOT turn the page into a scrapbook.

The photographs should remain the main visual focus.

--------------------------------------------------
17. ILLUSTRATIONS

- trees

- simple student-made drawings

Do NOT reserve huge portrait spaces.

Illustrations should feel like small marks inside a book.

18. BOOK PAGE DESIGN
--------------------------------------------------

The interior pages should look like contemporary printed book pages.

--------------------------------------------------

The final result must NOT look like:

- an old graduation album
- a vintage archive
- an antique scrapbook
- a corporate dashboard
- a modern SaaS website
- a social media feed
- a card-heavy portfolio

It SHOULD look like:

“A contemporary digital book made by a student to preserve three years of school memories.”

The physical book feeling should come from:

- composition
- whitespace
- page proportions
- typography
- subtle shadows
- index placement
- photographs
- page numbers

NOT from excessive textures or vintage decorations.

The book is simple and quiet.
